# neural-ocean

Deep-sea ecosystem sandbox driven by small neural networks and genetic mutations.

[Play Demo](https://sitrozyi.github.io/neural-ocean/)

![fish](assets/fish1.gif)

## Controls

- `Z`, `X`, `C`, `V`, `B` : Simulation speed (0x - 6x)
- `1` - `5` : Tools (Inspect, Feed, Meteor, Larva, Apex)
- `T` : Menu (Tools, Catalog, Save slots)
- `Space` : Reset camera / Deselect
- `Left drag` / `Wheel` : Pan / Zoom

## Notes

- Click a creature with Tool 1 (`Inspect`) to view its neural network activation.
- Discovered mutations are recorded in the in-game catalog (`T` > `Catalog`).
- World states can be saved across 3 browser storage slots (`T` > `Save`).
